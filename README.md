# GooogleMops 🐶💨

Бесполезная поисковая система. Мопс пердит, сопит, распускает слюни и принципиально не приносит пользы.

> Это не баг. Это концепция.

## Как запустить

Самый простой способ — открыть `index.html` двойным кликом.

Или:

- двойной клик по `start.bat`;
- либо запустить мини-сервер и открыть <http://localhost:8765/>:

```powershell
powershell -ExecutionPolicy Bypass -File .\serve.ps1
```

Внешние зависимости не нужны: всё работает на чистом HTML, CSS и JavaScript.

## APK для Android

Готовый файл: **`GooogleMops.apk`** в корне проекта (копия — `GooogleMops/GooogleMops.apk`). В GitHub-репозитории APK лежит в разделе **Releases**.

Как установить:

1. Перекиньте APK на телефон (кабель, облако, мессенджер).
2. Откройте файл на телефоне.
3. Разрешите установку из неизвестных источников для файлового менеджера или браузера.
4. Нажмите «Установить».

Требования: Android 5.0+ (API 21). Приложение работает офлайн, интернет не нужен. APK подписан debug-ключом — для личной установки этого достаточно, для Google Play понадобится собственный release-ключ.

Пересобрать APK:

```powershell
powershell -ExecutionPolicy Bypass -File .\android\build-apk.ps1
```

Скрипту нужны JDK 17 и Android SDK (platform 34 + build-tools 34.0.0); пути можно передать параметрами `-Jdk` и `-Sdk`.

## Что умеет

- **Пердеть** (клавиша `F`) — 15 настоящих MP3-записей, случайный выбор, иногда с добавкой.
- **Сопеть** (клавиша `S`) — 8 настоящих MP3-записей поросячьего сопения, случайный выбор, иногда с добавкой.
- **Распускать слюни** (клавиша `D`) — 6 настоящих MP3-записей чавканья и слюней, капли и лужа на совести.
- **Сделать ничего** (клавиша `N`) — мопс думает пару секунд, счётчик растёт, польза остаётся 0%.
- **Мопс-поиск** — выдаёт правдоподобные, но бесполезные результаты. Среди них всегда есть реклама слюней и мудрость Джейсона Стэтхэма.
- **77 мудростей Стэтхэма** — если искать «стэтхэм», «statham» или «мудрость». Цитаты выдуманы, как и польза.
- **Результат-фотография** — настоящий мопс крупным планом в поисковой выдаче. Красиво и совершенно бесполезно.
- Счётчики газов, всхрапов, миллилитров слюней и сделанного ничего — сохраняются между запусками.
- Регулятор громкости и кнопка сброса бесполезности.
- Достижения, тосты, пасхалки: наберите `польза` или введите Konami-код.
- Реалистичное фото мопса, вырезанное из снимка (никакой мультяшности).
- Звук можно выключить кнопкой `🔊` в шапке.

## Звук

Пуки проигрываются из 15 реальных MP3-файлов в `assets/sounds/`, слюни — из 6 отдельных записей чавканья, сопение — из 8 записей поросячьего хрюканья. При каждом нажатии выбирается случайная запись, иногда поверх неё добавляется вторая потише. «Ничего» синтезируется в реальном времени через Web Audio API. Громкость регулируется ползунком в пульте и применяется в том числе к уже играющим звукам.

Сопение: записи [JarredGibb](https://freesound.org/people/JarredGibb/) с Freesound, лицензия [Creative Commons 0](https://creativecommons.org/publicdomain/zero/1.0/): «Pig - Snort 1/4/5/6/7/10» и «Pig - Multiple Snorts 1/3».

## Картинка

Маскот — настоящая фотография мопса, предоставленная для проекта. Фон вырезан скриптом `tools/whitecut.ps1` (заливка от краёв, мягкая кромка, растворение нижнего края) в `assets/pug.png`. Исходник лежит в `assets/pug-new-raw.png`, прежний чёрный мопс сохранён в `assets/pug-black.png`.

## Структура

```
GooogleMops/
├── index.html      — разметка
├── styles.css      — стили и анимации
├── app.js          — звук, действия, поиск, мудрости, пасхалки
├── serve.ps1       — локальный статический сервер (опционально)
├── start.bat       — открыть приложение
├── assets/
│   ├── pug.png          — вырезанный мопс
│   ├── pug-new-raw.png  — исходное фото мопса
│   ├── pug-black.png    — прежний чёрный мопс
│   └── sounds/          — 15 пуков, 6 слюней и 8 записей сопения
└── tools/
    ├── whitecut.ps1 — вырезание белого фона
    └── chroma.ps1   — старый хромакей для прежнего мопса
```
